# Research & Design Rationale: Spatial Inventory & Equipment Grid

**Feature Branch**: `008-core-inventory-and-equipment` | **Date**: 2026-11-11

---

## 1. Spatial Container Topography & 2D Collision

The JX1 inventory system models physical item dimensions via a 2D cell occupancy matrix:

| Container Place | Value | Dimensions | Description |
| :--- | :---: | :--- | :--- |
| `pos_hand` | `1` | 1 item | Item currently attached to cursor during drag |
| `pos_equip` | `2` | 15 slots | Dedicated paper doll equipment slots (`0..14`) |
| `pos_equiproom` | `3` | 6x10 cells | Main player inventory bag (60 discrete cells) |
| `pos_immediacy` | `7` | 3 slots | Quick-access belt slots for medicines |

### 2D Footprint Collision Math
An item has integer dimensions `WidthCells` ($W$) and `HeightCells` ($H$).
When placed at top-left grid coordinate $(X, Y)$:
1. **Bounds Validation**:
   $$0 \le X \le 6 - W \quad \text{and} \quad 0 \le Y \le 10 - H$$
2. **Occupancy Matrix**:
   A 2D array `int[6, 10]` stores the runtime item ID residing in each cell (`0` if unoccupied).
   Every cell in $[X \dots X+W-1, Y \dots Y+H-1]$ must either be `0` or contain the single existing item being swapped.

## 2. Five-Elements Equipment Activation Chain

A cornerstone of character building is the Five-Elements generation cycle (*Ngũ Hành Tương Sinh*):

$$\text{Kim (0)} \longrightarrow \text{Thủy (2)} \longrightarrow \text{Mộc (1)} \longrightarrow \text{Hỏa (3)} \longrightarrow \text{Thổ (4)} \longrightarrow \text{Kim (0)}$$

### Light vs. Dark Affixes
Blue equipment generated by `KItemGenerator` contains up to 6 magic affixes:
- **Light Affixes (`0, 2, 4`)**: Always active and provide immediate stat bonuses regardless of other equipment.
- **Dark / Hidden Affixes (`1, 3, 5`)**: Inactive by default. They are unlocked when an equipped item in a generating slot matches the required generating series!

### Activation Topology
Equipment slots activate adjacent equipment according to defined circular relationships (e.g., Helm generates Armor, Armor generates Weapon, Weapon generates Boots). When an activating item of series $S_{\text{gen}}$ is worn such that $S_{\text{gen}}$ generates the target item's series $S_{\text{target}}$, the target item's hidden affixes are activated and apply their stat bonuses.

## 3. Wire Protocol Sequence & Cursor Safety

### 3.1 Move & Auto-Move Unlock Sequence
1. Client sends `c2s_playermoveitem` (`0x5B`, 7 bytes).
2. Server validates 2D footprint availability.
3. Server updates container coordinates and emits `s2c_playermoveitem` (`0x61`, 7 bytes).
4. Server immediately emits `s2c_ItemAutoMove` (`0x8E`, 1 byte).
   - *Why `0x8E` is mandatory*: The legacy game client locks mouse dragging upon sending `0x5B`. Without receiving `0x8E`, the cursor remains locked in drag mode, preventing further UI interactions.

### 3.2 Cursor-Hand Disconnect Safety
If a player socket drops or crashes while dragging an item (`pos_hand == 1`):
- The server interceptor invokes `PlayerInventoryGrid.SafelyReturnHandItem()`.
- The item is scanned against `pos_equiproom` to find the first continuous $W \times H$ free region.
- If the bag is full, the item is moved to storage or safe overflow.
- The character snapshot is then durably saved to the database, ensuring zero item loss or duplication.
